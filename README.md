# Skapto Kitchen

![Griffon](./public/griffon-404.png)

Somewhat simple project that aims to solve an annoying hassle within the dorms of AUBG - booking kitchens. The project uses Next.js for dealing with FE and BE; Pocketbase is used for DB and REST-ish API (self-hosted on a Raspberry Pi 5).

## Acknowledgements

- The project is not perfect. There are some design choices I regret, there are some bugs, there are some not so well-made implementations, some (a lot) unfinished stuff. 
- Some AI has been used - while I am not a fan of using AI for coding (for various reasons), some, mostly repetitive things *have* been coded using ChatGPT. They are marked by comment, usually in the beginning of the file (or function).
